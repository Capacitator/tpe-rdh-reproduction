# Four-pixel TPE NIST SP 800-22 evidence

This directory contains the NIST STS 2.1.2 assessment logs, final analysis reports, and manifests for the two 100-sequence, 1,000,000-bit stream families described in the conference report. The manifests record the input stream hashes and run configuration. The large generated ASCII input streams and the local STS source/build tree are retained in the local run workspace and are not included in this repository output.

The results are reported as statistical-test outcomes for these streams; they do not establish cryptographic security. Interpret the observed pass proportions using the discussion and limitations in the accompanying report.
